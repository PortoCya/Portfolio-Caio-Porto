Bem-vindo ao repositório do meu portfólio!  
Este projeto reúne minha identidade técnica como desenvolvedor e profissional de Redes e Cibersegurança: arquitetura limpa, design futurista, responsividade completa e interatividade moderna.

---

## ✨ Tecnologias Utilizadas

| Área | Ferramentas |
|------|-------------|
| **Estrutura** | HTML5 semântico e acessível (`aria-*`, SEO) |
| **Estilo** | CSS3 moderno, Design System com variáveis (Dark/Light Mode), Glassmorphism, HUD Futurista e Grid/Flexbox Responsivo |
| **Interatividade** | JavaScript modular, Rede de Partículas interativa em Canvas, Typing Effect bilíngue, Filtro de Projetos e Scroll Spy |
| **Internacionalização & Temas** | Alternância instantânea PT-BR / EN e Tema Escuro / Claro com persistência em `localStorage` |
